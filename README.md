## Euler Lagrange Solver
This program is rough generalisation of an Euler-Lagrange solver I coded for coursework for a university module. It is by no means complete or fully documented since it tends to struggle with quite a few BVPs. I'm working on a method involving Bézier curves  (see [here](https://github.com/MixtliMonroe/ActionMinimisationBezier)) which I hope will fix these problems.
<br>
Having said that, this solver is powerful enough to solve the Brachistochrone problem numerically, and simulate a pendulum all from just a lagrangian and boundary/initial conditions.
